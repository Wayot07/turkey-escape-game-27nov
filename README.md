Turkey Run — a turkey escape game: you are the turkey, the farmer is right behind you, and Thanksgiving dinner is on the line. Sprint across the farmyard at dusk, jump the fences, hay bales and the glowing-hot oven, slide under the farmer's spinning carving knives, grab the corn for points, and reach the forest gate 1500 m away before the farmer catches you. Three stumbles and dinner is served.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: `game/` is plain static files.

Controls: **Space / ↑ / click** — jump · **↓** — slide under knives · **P** — pause · **M** — sound on/off · **R** — run again after the end screen. The HUD shows score, distance, level, lives (tail feathers) and how close the farmer is.

Screenshots in `screenshots/` are real renders of this game's own code (`?shot=start|play|chase|end`).
